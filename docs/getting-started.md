# Getting started with avatar-agent-mcp

3D AI Agent Avatar — MCP server that spawns a textured GLB avatar, inspects/validates/optimizes any 3D model, gives the agent a Solana wallet + a voice, and ships full pump.fun powers (atomic Jito-bundled launches + creator-fee collection). Powered by three.ws.

## Install

```bash
npm install @three-ws/avatar-agent
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/avatar-agent-mcp.git
cd avatar-agent-mcp
```

Available commands:

| Command | Runs |
|---|---|
| `npm run start` | `node src/index.js` |
| `npm run test` | `node --test "test/**/*.test.mjs"` |
